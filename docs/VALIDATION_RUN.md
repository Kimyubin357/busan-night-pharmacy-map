# 2026-10-13 보완 검사 기록

## 격리된 원천 재계산

기존 최종 payload·그래프·거리행렬을 입력으로 재사용하지 않고, 별도의 검증 폴더에서 원천을 다시 읽었습니다. 실행 환경은 macOS ARM64, Python 3.12.14와 `requirements.txt`의 패키지 버전입니다.

- API 원본: 저장된 부산 JSON 전체 페이지와 NMC XML 전체 페이지를 해시 검증 후 재독해.
- 명단·생활인구: 원본 CSV·XLSX에서 재정제.
- 큰 원천: 도로명주소·연령인구·SGIS·OSM 원본을 SHA-256 대조 후 검증 폴더에 복사. 다운로드 서버의 현재 응답을 검증한 것은 아닙니다.
- 초기 실행: OSM PBF를 처음부터 파싱하고 보행 그래프와 거리행렬을 새로 생성. 약 155초 소요.
- 최종 실행: 같은 PBF의 해시가 일치하는 파싱 캐시를 사용하고 그래프·거리행렬·최종 데이터는 다시 생성. 17단계 모두 종료코드 0, 약 61초 소요.
- 최종 스냅샷 모드는 API 인증키 없이 통과했습니다.
- 실행 결과·코드 해시: `validation/snapshot_pipeline_run.json`.
- 기준 월·실제 OSM 시각·47개 원천 입력 해시: `validation/snapshot_run_context.json`.

이 시간은 이 장비의 측정치입니다. 다운로드 시간과 다른 장비의 성능은 포함하지 않습니다. 최신 API를 네트워크에서 전부 재수집하는 `latest` 모드는 이번 검사에서 실행하지 않았습니다.

## 수치 검증

- 격자·행정동 조각 21,963개, 분석 약국 1,696곳, 지도 약국 1,716곳, 공공심야 19곳.
- 동별·시간별 잠재수요 총량 보존.
- 운영 기준 2개 × 보행 기준 3개 × 후보 1,677곳의 점수 10,062개 독립 재집계.
- 20개 출발점의 정방향 경로와 역방향 거리행렬 일치.
- 거리행렬을 1250m까지 확장해 5km/h·15분 민감도를 완전히 계산.
- 기존 4km/h·15분 주모형의 접근 수요 하한/상한 및 후보 점수는 보완 전 결과와 일치.
- 민감도 기준 조건의 점수가 주모형과 일치.
- 5개 기간·스냅샷·이동한 경로 회귀 검사 통과.
- 6개 심야 시간 경계·익일·중첩 시간 검사 통과.

15분 API 기준에서 삼보약국은 4km/h에서는 1위, 3km/h에서는 85위입니다. 3km/h 시나리오의 선두는 연제봄약국입니다. 순위 변화를 확률·통계적 신뢰도 또는 현장 검증으로 해석하지 않습니다.

## 브라우저 검사

Browser 스킬이 제공되지 않아 설치된 Playwright와 임시 Chrome 프로필을 사용했습니다. 로컬 서버에서 데스크톱 1440×900, 노트북 1366×768, 모바일 390×844를 검사했습니다.

- 초기 화면과 5개 탭의 주요 내용 표시.
- 전체 목록 18페이지를 이동해 1,716곳 모두 표시 가능.
- 구 선택 전 동 비활성화, 구 선택 후 동 활성화 및 구 이름 중복 제거.
- 23시 폐점 약국은 22–23시로 표시, 일요일 결과 팝업도 일요일로 표시.
- 공공심야 19곳과 상위 지도 레이어 유지.
- 시계 자동 갱신, 검색 결과 없음, 페이지 버튼 비활성화.
- 미충족 수요, 후보 추가 색상·참고 원·선정 이유, 범례 항목 줄바꿈.
- 민감도 2개 운영 기준 × 3개 도보 기준에서 5가지 조건 표시.
- 노트북 지도 전체 높이가 768px 화면 안에 맞고 모바일 가로 넘침 없음.
- JavaScript 실행 오류 0건.

브라우저 실행 결과는 `validation/browser_checks.json`에 보관합니다. 실제 방문 경로·약국 현장 영업·전화 확인은 아직 실시하지 않았으며 `field_validation_plan.csv`에 미실시 상태로 기록했습니다.
