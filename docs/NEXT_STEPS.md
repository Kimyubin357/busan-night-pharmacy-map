## 후속 작업 상태

1. **Cloud Run 배포 완료**: [공개 대시보드](https://busan-night-pharmacy-map-768810209035.asia-east1.run.app/). DB 없이 요청 기반 과금·인스턴스 0~1개로 배포했습니다. 같은 결제 계정의 두 프로젝트와 기존 서비스 2개를 확인했으며 기존 리비전은 유지했습니다. 배포본과 `serve.py`만 이미지에 포함합니다. 세부 구성과 비용은 [배포 안내](CLOUD_RUN.md)를 확인합니다.
2. **전화·현장 검증 제외**: 사용자가 수행하지 않으며 계획도 없다고 명시했습니다. 과거 생성된 `field_validation_plan.csv`는 미실시 검토 목록으로만 보존하고 현재 할 일로 제시하지 않습니다. 현장 검증을 했다는 표현도 사용하지 않습니다.
3. **SQL·DB 설계 보류**: 사용자가 현재 배포는 DB 없이 진행하도록 결정했습니다. 필요성이 생겼을 때 약국·요일별 시간·수집 이력·출처 분리를 검토합니다.
4. **Docker 관리 제거 / CI/CD 미구현**: Dockerfile과 .dockerignore를 제거하고 최소 소스 배포 준비를 추가했습니다. 배포 사이트·실행 이미지는 유지합니다. CI/CD는 선택 사항이며 이번 작업에서 구현하지 않습니다.
5. **포트폴리오 문서 정정 / 사이트 반영 보류**: 사실 대조와 역할·한계 설명을 정리합니다. 실제 포트폴리오 사이트 반영은 사용자가 재개할 때까지 수행하지 않습니다. 시연 영상/PDF는 선택 사항입니다.
6. **선택 사항**: 프레임워크(Vue/Next 등) 활용 경험, 목표·정답·평가지표가 명확한 AI/ML 실험. 기존 공간 분석에 모델 이름만 붙이지 않습니다.

## 4번 초기 로딩 개선 완료 (2026-10-14)

- 웹 첫 화면은 요약 자료만 읽고, 운영 약국 찾기와 접근성 지도 자료·코드는 해당 탭을 처음 열 때 읽습니다. 지도 계산·대량 점 생성도 지도 탭을 열 때 실행합니다.
- 웹본 `dist/index.html`은 약 25KB이며, 첫 화면 필수 파일 합계는 약 1.10MB입니다. 기존 단일 HTML 약 8.98MB보다 약 88% 작습니다. HTTP gzip을 적용한 필수 파일 합계는 약 1.02MB입니다. 타일·HTTP 헤더는 제외하며, 실제 접속시간 개선율을 측정한 값은 아닙니다.
- 데이터·글꼴 내장 단일 HTML은 `dist/downloads/busan-night-pharmacy.html`로 유지합니다. 웹 게시에는 `dist` 전체가 필요합니다.
- 압축·ETag·해시 파일 캐시 서버, 실패 재시도, 분리 데이터 원본 일치 검사와 실제 브라우저 검사를 추가했습니다. 원천 자료·분석 결과·디자인은 유지했습니다.
- 이 성능 개선 당시에는 배포 전이었습니다. 이후 Cloud Run 배포를 완료했으며 과거 Git 이력 키 파일은 후속 요청으로 제거했습니다.
