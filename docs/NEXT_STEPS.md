# 포트폴리오 다음 작업

사용자가 “이제 뭐할까?”라고 물으면 이 기록에 따라 아직 하지 않은 일을 안내합니다. 마지막 범위 결정: 2026-10-13.

## 현재 요청

1. 원천부터 재실행하는 파이프라인: 기간·수집일·해시 통합, 정책 시간표 연결, 검증 자동화.
2. 후보 선정 설명: 보행속도·일요일 휴무 가정·수요 배분 민감도, 미충족 수요 지도.
3. 약국 찾기 UX: 전체 목록 페이지 이동, 부분 심야영업 문구, 팝업 요일, 동 이름, 범례, 데이터 조회일.

**1~3번의 코드 보완과 스냅샷 원천 재계산·화면 검사는 완료했습니다.** 2026-10-13에는 최신 부산·NMC API 전체 재수집 및 전체 파이프라인 검사도 완료했습니다. 현장·전화 확인은 아직 하지 않았습니다.

완료 여부와 검사 기록은 `docs/REPRODUCING.md`와 `docs/VALIDATION_RUN.md`에서 확인합니다.

현재 수정본은 로컬 Git에 저장되어 있습니다. Cloud Run 배포 전에 원격 GitHub 반영 여부를 확인합니다.

## 아직 하지 않은 일 (우선순위)

1. **Cloud Run 배포**: 사용자가 원하는 배포 대상입니다. 기존에 다른 서비스 1개가 있으므로 현재 결제 계정 사용량과 리전을 확인하고 비용 제한 설정을 준비합니다. 무료 한도는 서비스별 추가 지급이 아닙니다. 배포 컨테이너에는 `dist`만 포함하고 `.env`·원천 분석 데이터는 넣지 않습니다.
2. **실제 도보·운영시간 표본 검증**: `field_validation_plan.csv`의 상위 후보 및 경로를 직접 확인하고 확인 날짜·증빙을 채웁니다. 현재는 미실시입니다. 알고리즘 일치 검사를 현장 정확도 검증으로 표현하지 않습니다.
3. **SQL·DB 설계**: 약국·요일별 시간·수집 이력·출처를 분리한 ERD와 SQL 조회/집계. 필요성이 있는 범위로 구현합니다.
4. **Docker·GitHub Actions CI/CD**: 환경 고정, 검사 후 배포, 실패 시 이전 배포 유지.
5. **지원용 포트폴리오 자료**: 네패스 AI정보화파트 지원 맥락에서 문제·구조·본인 역할·결측 판단·검증·결과·한계 설명, 데모 링크와 시연 영상/PDF.
6. **선택 사항**: 프레임워크(Vue/Next 등) 활용 경험, 목표·정답·평가지표가 명확한 AI/ML 실험. 기존 공간 분석에 모델 이름만 붙이지 않습니다.

## 본인 기여와 표현

- 사용자 진술: 프로젝트를 거의 혼자 수행했습니다. 기존의 “팀원 역할”을 임의로 크게 잡지 않습니다.
- 정확한 기여율, 팀원의 보고서 작업, AI 사용 범위는 실제 수행 기준으로 설명합니다.
- 후보 점수는 실제 방문자나 이용 증가가 아니라 가정에 따른 추가 접근 잠재수요입니다.
- Cloud Run 배포 경험은 AWS 경험과 구분합니다. 현재 프로젝트는 학습한 예측/분류 모델을 사용하지 않았습니다.
