# 분석 방법과 데이터 변환

## 1. 공급 데이터

부산 약국 API 전 페이지를 수집하고 부산 주소만 남깁니다. 공공심야 명단은 이름·전화·주소의 강한 식별정보로 기존 약국에 속성을 붙입니다. NMC 기관 ID와 이름·전화·200m 이내 위치를 확인한 뒤 운영시간을 대조합니다. 충돌한 요일은 NMC 조회값을 사용합니다.

월요일이 미상이고 화~금 시작·종료가 모두 같으면 그 시간을 월요일에 적용합니다. 화~금 시간표가 있고 원본과 NMC의 토·일 시간이 모두 공란이면 일반약국의 주말 휴무로 가정합니다. 공공심야약국은 정책 운영시간을 적용합니다. 변경 전후와 근거는 `schedule_assumptions_audit.csv`에 남깁니다.

## 2. 잠재수요

부산 생활인구의 동별 22·23·00시 주거·직장·방문인구 합계를 사용합니다. SGIS 100m 총인구가 동 안에서 차지하는 비율로 동별 총량을 격자에 배분합니다. 경계 격자는 면적 비율로 분할하고 동별 총량 보존을 검증합니다. 실제 약국 방문자나 의약품 구매량은 아닙니다.

## 3. 보행망

OSM PBF에서 보행 가능한 highway를 추출합니다. 좌표는 EPSG:5179로 투영하고 출발점과 약국을 가장 가까운 실제 도로 구간에 붙입니다. 100m를 넘는 연결은 확정 경로에서 제외하고 불확실성으로 유지합니다. 속도는 4km/h이며 경사·계단 감속과 회전 제한은 반영하지 않습니다.

## 4. 접근성

각 격자의 출발시각에 보행시간을 더한 도착시각으로 약국 영업 여부를 판정합니다. 5·10·15분 기준에서 시간표상 접근 확인, 판단 유보, 기준 밖을 분리합니다.

## 5. 후보 순위

비지정 약국을 매일 22시~익일 01시 운영한다고 하나씩 독립적으로 가정합니다. 7요일 × 3개 시각의 추가 접근 잠재수요 평균을 계산합니다. 기존 공급을 낙관적으로 봐도 늘어나는 수요를 하한, 보수적으로 볼 때 가능한 개선을 상한으로 표시하며 순위는 하한 기준입니다.

## 6. 검증

동별 수요 총량 보존, 10,062개 후보 점수 재집계, 정방향 도로 최단경로 표본, 운영시간 가정 조건과 NMC 충돌 적용, 지도 레이어·필터 조합을 검사합니다. 계산 재현 검증은 실제 도보 경로나 현장 영업의 정확도 검증이 아닙니다.
